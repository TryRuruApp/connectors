# Ruru Plugins Repository

Official dynamic connector plugins for [Ruru](https://github.com/TryRuruApp).

## Available Connectors
- **GitHub Connector** (`@github`): Read issues, PRs, and search code across your repositories.
- **Linear Connector** (`@linear`): Access Linear issues, projects, and active cycles.
- **Apple Calendar Connector** (`@applecalendar`): Read events, search schedule, and create calendar entries via EventKit.

## Structure
- `manifest.json`: Catalog metadata with SHA-256 checksums and branding icons.
- `icons/`: Official SVG vector marks for catalog presentation.
- `bundles/`: Compiled `.bundle.zip` packages for 1-click on-demand installation.
